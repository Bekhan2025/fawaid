# AGENTS.md

Контекст для ИИ-агента, работающего с этим репозиторием. Прочитай целиком перед
правками: в проекте есть генерируемые файлы и неписаные правила оформления, нарушение
которых ломает данные или внешний вид.

## 1. Суть проекта

Интерактивная читалка книги Ибн Каййима аль-Джаузиййи «аль-Фаваид» по русскому изданию
(М.: Умма, 2013, 480 с.). Один смысловой блок (запись оглавления) показывается в трёх
слоях, переключение — табы в шапке:

- **`book`** — «Книга»: полный текст издания. Минималистичный «книжный» вид,
  без декоративного оформления: сплошные абзацы, сноски, стихи. Решение владельца
  проекта: этот слой специально не «украшать».
- **`razbor`** — «Разбор»: структурированные тезисы, подготовленные составителем.
- **`atlas`** — «Атлас»: визуальные примитивы (шкалы −5…+5, карточки примеров XXI века,
  шаги практики).

Полный текст книги уже перенесён в слой `book` для всех 136 записей. Слои `razbor`/
`atlas` готовы только для записи **e310 «Золотая середина»** (глава `ch1`) — они служат
эталоном стиля для следующих глав. Их наполняют **по одной записи**.

## 3. Модель данных — минимум, без которого можно сломать всё

- Навигация строится из `BOOK.parts` (это `TOC_PARTS`). Активная запись — по `id`
  (`e310` и т.п.). Порядок чтения — сортировка по `page` издания (`reader-app.tsx`).
- Текст слоя «Книга» — `BOOK_TEXT[entryId]`, т.е. записи из `p*.json`.
- Связь «запись → готовая глава»: `chapterId` в записи. Источник значения —
  `src/content/toc.ts` (её парсит `extract_book.py` и переносит в JSON).
  По умолчанию открыта запись `e310` (константа `DEFAULT_ENTRY`).
- Абзацы `BookPara`:
  - строка — обычный абзац; `{{n}}` — маркер сноски (рендерится в верхний индекс);
  - `{ "verse": ["строка 1", "строка 2"] }` — стихотворная цитата;
  - `{ "center": "текст" }` — центрированный блок (басмала).
- Инлайн-разметка в любых текстах: `**жирный**`, `[[term:id]]` (термин из `BOOK.terms`),
  `{{n}}` (только в слое «Книга»).
- `Section.additionOnly: true` — секция целиком дополнение составителя (показывается
  с пометкой). Атлас-примитивы: `mini` (3 точки на шкале), `spectrum` (строки × 5 зон
  `k0…k4`), `examples` (карточки минус/ноль/плюс), `steps` (карточки шагов).

## 4. Как добавить главу «Разбор» / «Атлас» (рецепт)

1. Выбрать запись по её `id` в `src/content/toc.ts`, прочитать её текст в
   `src/content/book-text/p*.json`.
2. Составить разбор ТОЛЬКО из содержания записи: тезисы без выдумок, современные
   примеры допустимы только в блоке «XXI век» и только как иллюстрация.
3. Добавить новые термины (если нужны) в `BOOK.terms` в `src/content/book.ts`
   (`id`, `ru`, `ar`, `translit`, `short`, `note`).
4. Создать главу в `BOOK.chapters`: `id: "chN"`, `num`, `title`, `subtitle`,
   `sections[]` с `razbor` и/или `atlas` (см. эталонную `ch1`).
5. Привязать: в `src/content/toc.ts` у записи поставить `chapterId: "chN"`, затем
   перегенерировать JSON (`python3 scripts/extract_book.py`), чтобы `chapterId`
   попал в `p*.json`. Быстрая альтернатива без перегенерации — поправить
   `chapterId` прямо в нужном `p*.json` (это отклонение от процесса; допустимо
   для одной строки).
6. Проверить в браузере: табы слоёв на реальных кликах, hover-подсветку на
   `SpectrumBoard`, мобильную ширину 390px, консоль без ошибок, `bun run lint` чист.

Числа/факты в примерах — только проверяемые или явно оценочные («например», «условный
пример»). Аяты и хадисы не paraphrase-ить по памяти — брать формулировки из текста записи.

## 5. Дизайн-система

- Палитра: «бумага» `#f5f1e8` / «чернила» `#22302a`, акцент — зелёный `#1e8449`
  (семантика середины), тёмная тема — через `.dark` (`next-themes`, `ThemeToggle`).
- Шрифты: Manrope (UI), Playfair Display — класс `book-serif` (заголовки/текст книги),
  Amiri — класс `font-arabic` (арабский, всегда `dir="rtl"`).
- Шкала качеств: классы точек `k0`/`k4` (красные края), `k1`/`k3` (умеренные),
  `k2` (зелёная середина) — градиенты и цвета описаны в `globals.css`.
- `addition-box` — пунктирная рамка для помеченных дополнений составителя.
- Слой «Книга» — намеренно скудный: никаких градиентов, карточек и теней вокруг
  текста издания. «Красота» допустима только в слоях «Разбор»/«Атлас» и в шапке.
- Компоненты shadcn/ui лежат в `src/components/ui/` — брать готовые (Tabs, Popover,
  Sidebar), не изобретать свои.

## 6. Команды

```bash
bun install
bun run dev      # http://localhost:3000, лог в dev.log
bun run lint     # ESLint — должен быть чистым перед сдачей
bun run build    # production (standalone)
bun run start    # запуск собранного
```

Python-скрипты контента: `python3 scripts/extract_book.py`, `python3 scripts/parse_toc.py`
(нужны `fitz`/PyMuPDF и `pdftotext`). Скрипты читают `upload/ru_fawaid.pdf` и пишут
в `src/content/` — их вывод не править руками.

## 7. Известные подводные камни

- Radix Tabs не реагируют на синтетические `dispatchEvent`-клики — в проверках
  только реальные клики по `role="tab"`, hover — реальное движение мыши.
- Сайдбар: номер записи — `flex-none`, заголовок — отдельный `truncate` (иначе цифры
  обрезаются).
- Мобильное нижнее меню закрывается через `setOpenMobile(false)` из `useSidebar`
  при переходе по записи.
- Извлечённый текст содержит редкие артефакты OCR; точечные исправления накапливаются
  в списках `OCR_WORD_FIXES` / `DC_SPACE_FIXES` в `scripts/extract_book.py`, а не
  правками JSON.
- В тексте издания используется знак ﷺ (ортнамент из PDF-изображений) — не заменять
  и не удалять.

## 8. Принципы контента (обязательные)

1. Авторский текст — только из издания; не переписывать его «красивее».
2. Любое дополнение составителя — с пометкой (`additionOnly` / `addition-box`).
3. Слой «Книга» — минимализм; слои «Разбор»/«Атлас» — выразительные, но в палитре.
4. Работать по одной записи за раз: перенёс → проверил в браузере → следующая.
5. Никаких заглушек вида «TODO» в пользовательском контенте: запись без разбора
   честно показывает `EntryPlaceholder` с переходом в слой «Книга».
